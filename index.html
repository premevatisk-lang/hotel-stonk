🔧 ยังไม่ได้เชื่อมต่อฐานข้อมูล Firebase

เปิดไฟล์ inventory-app.html นี้ด้วยโปรแกรมแก้ไขข้อความ (เช่น Notepad, VS Code) แล้วมองหาตัวแปร firebaseConfig ใกล้ท้ายไฟล์ จากนั้นใส่ค่าที่ได้จากโปรเจกต์ Firebase ของคุณแทนที่ข้อความ "ใส่..." ทั้งหมด

  1. ไปที่ console.firebase.google.com แล้วสร้างโปรเจกต์ใหม่ (ฟรี)
  2. เมนูซ้าย → Build → Firestore Database → Create database → เลือก Start in test mode
  3. Project settings (รูปเฟือง) → เลื่อนลงมา "Your apps" → กดไอคอน </> เพื่อเพิ่มเว็บแอป → ตั้งชื่อแล้วกด Register
  4. คัดลอกก้อนโค้ด firebaseConfig ที่ขึ้นมา มาแปะแทนที่ในไฟล์นี้
  5. บันทึกไฟล์ แล้วอัปโหลดขึ้น GitHub / รีเฟรชหน้านี้ใหม่
